# Редакционная проверка: country-finder (RU/EN)

- Цель: интерактивно сузить выбор страны по бюджету, карьере, семье или долгосрочному статусу.
- Конкуренты из живого поиска, 2026-10-26: Where I Can Live, CountryToLive, WhereNext, SettleRadar, WiggMap.
- Что сделано лучше: нет непрозрачного общего балла; результат объясняет компромисс и ведёт на страновой гайд и официальный источник.
- Ключевые фразы Serpstat: не выгружались по прямому указанию пользователя; метрики не отмечены как проверенные.
- Источники: World Bank и официальные визовые порталы стран из shortlist.
- Авторский опыт: не использовался.
- Техническая проверка: маршруты RU/EN — 200, JS загружается отдельно, результат доступен через `aria-live`, canonical и hreflang присутствуют.
- Статус: готово к публикации; данные о праве на визу пользователь должен проверять по паспорту.
