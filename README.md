# Python Tasks

Сайт Relocate to Asia на Flask: русская и английская версии, SQLite, статьи и инструменты планирования переезда.

## Запуск

```powershell
python app.py
```

После запуска откройте в браузере:

```text
http://127.0.0.1:5000
```

Контент и показатели сайта Relocate to Asia находятся в `content.db`.

## Данные и API

- Сравнение стран получает население и площадь из `/api/countries/<ISO2>`. Сервер читает сохранённые наблюдения World Bank; год показан рядом со значением.
- Климат загружается из Open-Meteo за завершённый годовой период с недельным отступом от текущей даты.
- Курсы ExchangeRate-API используются только после проверки ответа и свежести. До загрузки курса и при ошибках калькуляторы показывают USD. Запросы ограничены десятью секундами.
- Устаревший REST Countries v3.1 больше не используется. Для сравнения стран не нужен API-ключ.

Обновление сохранённых показателей выполняется вручную:

```powershell
python sync_countries.py
```

Скрипт сохраняет резервную копию в `.backups/`, запрашивает последние непустые наблюдения и обновляет только валидные поля. Ошибки API не очищают сохранённые данные. Для каждого показателя хранится отдельный год; дата запроса находится в `wb_checked_at`. После синхронизации перезапустите веб-процесс, чтобы сбросить кеш HTML. Автоматическое расписание обновлений не настроено.

`init_db.py` — старый импортёр WordPress, не часть обычного запуска или деплоя. Он отключён без `WORDPRESS_SOURCE_URL`, который должен указывать на доступный WordPress-архив. Текущий сайт на Flask не предоставляет WordPress API.

## Проверка интеграций

Для сценариев JavaScript нужен установленный Node.js:

```powershell
python scripts/test_api_integrations.py
```

Тесты проверяют частичные ответы, сохранение данных при ошибках, просроченные курсы и расчёты обеих языковых версий до и после ответа API.

## Технические проверки

Для создания и содержательного обновления статей действует [обязательный редакционный промпт](docs/blog-writing-prompt.md), включая подбор ключевых фраз Serpstat и проверку источников. Правило закреплено в [AGENTS.md](AGENTS.md). Результаты для каждой статьи сохраняются в `docs/content-reviews/<slug>-<lang>.md`; технические тесты не заменяют редакционную проверку.

```powershell
python scripts/technical_audit.py
python scripts/test_technical_regressions.py
python scripts/test_editorial.py
python scripts/seo_audit.py
python scripts/content_quality_audit.py
python scripts/ru_localization_audit.py
```

Технический обход читает полный XML sitemap, включая локализованные страницы, и проверяет HTTP-ответы, внутренние ссылки и якоря, ресурсы, canonical, взаимные hreflang, JSON-LD, H1, дубли ID и метаданных. Выполняется локально через Flask test client, без сетевых запросов; не заменяет визуальную проверку и измерение Core Web Vitals в браузере.

HTML-кеш живёт десять минут с момента генерации; попадания в кеш не продлевают этот срок. CSS и JS в базовом шаблоне получают версию по хешу содержимого, чтобы после деплоя браузеры загружали изменённые файлы.
